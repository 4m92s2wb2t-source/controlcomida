Algoritmo de Intersección Familiar Activo

El motor cruza todas las restricciones simultáneamente. Si un alimento es beneficioso para el Papá pero prohibido para el Niño (o irritante para la Mamá), el sistema lo bloqueará del menú común o propondrá una adaptación de 1 solo toque.
